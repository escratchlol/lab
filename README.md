# Домашнее задание к работе 11

## Условие задачи
С одномерным массивом, состоящим из *n* вводимых с клавиатуры положительных и отрицательных целых чисел, выполнить вычисление:
суммы порядковых номеров элементов массива, расположенных после максимального элемента массива.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Установить локаль для корректного отображения кириллицы: `setlocale(LC_ALL, "Ru")`.
3. Ввести количество элементов массива `n` (не более `N`).
4. Объявить массив целых чисел `A[N]`
5. Заполнить массив с клавиатуры: для `i` от `0` до `n-1` запросить `A[i]`.
6. Вывести исходный массив.
7. Вызвать функцию `index_max(A, n)` для поиска индекса максимального элемента.
8. Вызвать функцию `sum_index_max(A, n)` для вычисления суммы порядковых номеров элементов, расположенных после максимального.
9. Вывести найденный индекс максимального элемента.
10. Вывести сумму порядковых номеров элементов после максимального.
11. **Конец**.

**Часть 2: Функция поиска индекса максимального элемента (`index_max`)**
1. **Начало функции**: получение массива `A` и количества элементов `n`.
2. Присвоить `imax = 0`.
3. Цикл по `i` от `1` до `n-1`:
     - если `A[i] > A[imax]`, то `imax = i`.
4. Вернуть `imax`.
5. **Конец**.
   
**Часть 3: Функция вычисления суммы порядковых номеров после максимального (`sum_index_max`)**
1. **Начало функции**: получение массива `A` и количества элементов `n`.
2. Получить `imax = index_max(A, n)`.
3. Присвоить `sum = 0`.
4. Цикл по `i` от `imax + 1` до `n-1`:
     - `sum += i + 1` (порядковый номер элемента, нумерация с 1).
5. Вернуть `sum`.
6. **Конец**.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

#define N 10

int index_max(float A[], int n);
int sum_index_max(float A[], int n);

int main()
{
    setlocale(LC_ALL, "Ru");

    puts("задание 3");

    float R[N];

    for (int i = 0; i < N; i++)
    {
        printf("a[%d] = ", i + 1);
        scanf("%f", &R[i]);
    }

    printf("индекс максимального элемента= %d\n", index_max(R, N));
    printf("сумма индексов, начиная с максимального элемента= %d\n", sum_index_max(R, N));

    return 0;
}

int index_max(float A[], int n)
{
    int imax = 0;
    for (int i = 1; i < n; i++)
        if (A[i] > A[imax])
            imax = i;
    return imax;
}

int sum_index_max(float A[], int n)
{
    int imax = index_max(A, n);
    int sum = 0;
    for (int i = imax; i < n; i++)
        sum += i;
    return sum;
}
```
