## Условие задачи
Составить программу, которая проверяет, принадлежит ли заданная пользователем точка с координатами (x, y) заданной закрашенной (заштрихованной) области, и выводит на экран соответствующее сообщение.

## 1. Алгоритм и блок-схема

### **Математическая модель:**

Перед составлением алгоритма найдем уравнения прямых, ограничивающих заштрихованную область, по графику.

**Верхняя прямая (красная):** проходит через точки (0; 6) и (1; 5). Уравнение прямой y=kx+b.
   - b=6
   - 5=k⋅1+6⇒k=−1
   - Уравнение: y=−x+6

**Нижняя прямая (фиолетовая):** проходит через точки (0; 4) и (1; 2).
   - b=4
   - 2=k⋅1+4⇒k=−2
   - Уравнение: y=−2x+4

Область находится ниже верхней прямой (y≤−x+6) и выше нижней прямой (y≥−2x+4), а также ограничена осями координат (x≥0,y≥0) и прямой x=6.

## 2. Реализация программы

#include <stdio.h>
#include <stdlib.h>
#include <locale.h>
#include <math.h>

int dz(float x, float y);

int main() {
    setlocale(LC_ALL, "Ru");
    
    float x1, y1;
    printf("Введите x: ");
    scanf("%f", &x1);
    printf("Введите y: ");
    scanf("%f", &y1);
    
    int result = dz(x1, y1);
    
    if (result == 1) {
        printf("Точка (%.2f, %.2f) принадлежит области\n", x1, y1);
    }
    else {
        printf("Точка (%.2f, %.2f) не принадлежит области\n", x1, y1);
    }
    
    return 0;
}

int dz(float x, float y) {
    if (x > 6 || x < 0 || y > 6 || y < 0) {
        return -1;
    }
    if (y > -1.0 * x + 6.0) {
        return -1;
    }
    if (y < -2.0 * x + 4.0) {
        return -1;
    }
    return 1;
}
