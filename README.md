# Домашнее задание к работе 7

## Условие задачи
Написать программу, которая по введенному возрасту в месяцах выводит возрастную категорию ребенка (новорожденный – до 2 мес., младенец – до 1 года; 
раннее детство – 1-3 года; дошкольник – 3-7 лет; школьник – 7-13 лет, подросток – 13-17 лет). Для старших возрастов выводится категория "взрослый".

## 1. Алгоритм и блок-схема

### **Алгоритм**
1. **Начало**
2. Подключить необходимые библиотеки:
    - `<stdio.h>` - для ввода и вывода данных (printf, scanf).
   - `<locale.h>` - для работы с локалью (поддержка русского языка).
3. Объявить прототип функции `int age(int num)` для определения возрастной категории.
4. Определить функцию `main()` - точку входа в программу:
   - Установить локаль для корректного отображения кириллицы: `setlocale(LC_ALL, "Ru")`.
   - Объявить целочисленную переменную `num` (количество месяцев).
   - Запросить у пользователя и считать с клавиатуры значение `num` с помощью функции `scanf`.
   - Вызвать функцию `age(num)`, передав ей значение месяцев, и сохранить результат вызова в переменную result3.
   - Используя оператор `switch` для переменной `result3`, вывести на экран соответствующее сообщение (например, если `result3 == 1`, вывести "новорожденный", если `-1` — "ошибка" и т.д.).
   - Завершить программу, вернув 0.
5. В теле функции `age(int num)`:
   - Проверить, является ли возраст отрицательным (num < 0). Если да, вернуть -1 (код ошибки).
   - Проверить, меньше ли возраст 2 месяцев (num >= 0 && num < 2). Если да, вернуть 1 (новорожденный).
   - Вычислить полное количество лет: int year = num / 12.
   - С помощью оператора switch определить категорию по переменной year:
       - case 0: вернуть 2 (младенец).
       - case 1, 2: вернуть 3 (раннее детство).
       - case 3, 4, 5, 6: вернуть 4 (дошкольник).
       - case 7, 8, 9, 10, 11, 12: вернуть 5 (школьник).
       - case 13, 14, 15, 16, 17: вернуть 6 (подросток).
       - default: вернуть 7 (взрослый).
6. **Конец**

## 2. Реализация программы

#include <stdio.h>
#include <locale.h>

int age(int num);

int main()
{
    setlocale(LC_ALL, "Ru");

    int num;
    printf("Введите число месяцев ребенка: ");
    scanf("%d", &num);

    int result3 = age(num);
    
    switch (result3)
    {
    case -1:
        puts("Ошибка");
        break;
    case 1:
        puts("Новорожденный");
        break;
    case 2:
        puts("Младенец");
        break;
    case 3:
        puts("Раннее детство");
        break;
    case 4:
        puts("Дошкольник");
        break;
    case 5:
        puts("Школьник");
        break;
    case 6:
        puts("Подросток");
        break;
    case 7:
        puts("Взрослый");
        break;
    default:
        break;
    }
    return 0;
}

int age(int num)
{
    if (num < 0) {
        return -1;
    }

    if (num >= 0 && num < 2) {
        return 1;
    }

    int year = num / 12;
    switch (year)
    {
    case 0:
        return 2;
        break;
    case 1: case 2:
        return 3;
        break;
    case 3: case 4: case 5: case 6:
        return 4;
        break;
    case 7: case 8: case 9: case 10: case 11: case 12:
        return 5;
        break;
    case 13: case 14: case 15: case 16: case 17:
        return 6;
        break;
    default:
        return 7;
    }
}
