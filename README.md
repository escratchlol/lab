# Домашнее задание к работе 10

## Условие задачи
Составьте программу, которая для заданной пользователем фигуры (четырехугольника, задаваемого диагоналями и углом между ними) предлагает меню выбора одной из операций:
1) рассчитать площадь;
2) вывести определение фигуры;
3) нарисовать фигуру.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Инициализация локализации для корректного вывода кириллицы.
3. Ввод исходных данных с клавиатуры (внутри цикла меню):
  - Ввести символ для рисования sym.
  - Ввести длину первой диагонали d1.
  - Ввести длину второй диагонали d2.
  - Ввести угол между диагоналями ang (в градусах).
4. Вывод меню и считывание выбора пользователя op.
5. Многоальтернативный выбор (switch по значению op):
  - При op == 1: Проверить параметры функцией param_ok. Если верно, вызвать функцию S(d1, d2, ang) и вывести площадь.
  - При op == 2: Вывести текстовое определение четырехугольника.
  - При op == 3: Проверить параметры. Найти максимальные и минимальные координаты вершин с помощью vx и vy. Запустить вложенные циклы (по строкам r и колонкам cx). На каждом шаге вызывать f_char(x, y, ...) и выводить полученный символ.
  - При op == 0: Выйти из цикла (завершить программу).
  - Иначе (default): Вывести сообщение об ошибке.
6. Проверка условия цикла: если op != 0, повторить шаги 3-5.
7. **Конец**.

**Часть 2: Функция расчета площади (S)**
1. **Начало функции**: получение параметров d1, d2, a.
2. Перевод угла из градусов в радианы.
3. Вычисление площади по формуле: S=0.5⋅d1⋅d2⋅sin(a).
4. Возврат значения в main.
5. **Конец**.

**Часть 3: Функция проверки параметров (param_ok)**
1. **Начало функции**: получение d1, d2, ang.
2. Если d1≤0 или d2≤0 или угол ≤0 или ≥180, вернуть 0 (ошибка).
3. Иначе вернуть 1 (успех).
4. **Конец**.
