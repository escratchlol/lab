# Домашнее задание к работе 10

## Условие задачи
Составьте программу, которая для заданной пользователем фигуры (четырёхугольник, задаваемый диагоналями d1, d2 и углом α между ними) предлагает меню выбора одной из операций:
1) рассчитать площадь;
2) вывести определение фигуры;
3) нарисовать фигуру.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Установить локаль для корректного отображения кириллицы: setlocale(LC_ALL, "Ru").
3. Ввести исходные данные: длины диагоналей d1, d2 и угол между ними ang (в градусах).
4. Организовать бесконечный цикл для работы меню:
  - Вывести пункты меню:
    - 1 – рассчитать площадь;
    - 2 – вывести определение фигуры;
    - 3 – нарисовать фигуру;
    - 0 – выход.
  - Считать номер операции op.
  - Если op == 0, выйти из цикла.
  - Многоальтернативный выбор (switch по op):
    - case 1: если param_ok(d1, d2, ang) ложно, вывести сообщение об ошибке; иначе вычислить S(d1, d2, ang) и вывести площадь.
    - case 2: вывести текстовое определение четырёхугольника.
    - case 3: если param_ok ложно, вывести ошибку; иначе:
      - запросить символ sym для рисования;
      - вычислить границы отрисовки: ymax = max(vy(1..4)), ymin = min(vy(1..4)), xmax = max(vx(1..4)), xmin = min(vx(1..4));
      - цикл по строкам r от ceil(ymax) до floor(ymin) (шаг −1);
      - цикл по столбцам cx от floor(xmin * 2) до ceil(xmax * 2) (шаг +1);
      - для каждой точки вывести f_char(cx * 0.5, r, d1, d2, ang, sym);
      - после строки вывести \n.
    - default: вывести сообщение «Неверный выбор! Попробуйте снова.».
5. **Конец**.

**Часть 2: Функция проверки параметров (param_ok)**
1. **Начало функции**: получение d1, d2, ang.
2. Если d1≤0 или d2≤0 или ang <= 0 или ang ≥ 180, вернуть 0 (ошибка).
3. Иначе вернуть 1 (успех).
4. **Конец**.
   
**Часть 3: Функция расчета площади (S)**
1. **Начало функции**: получение параметров d1, d2, a (угол в градусах)..
2. Вычислить площадь по формуле: S = 0.5 * d1 * d2 * sin(a * PI / 180).
3. Вернуть значение S.
4. **Конец**.

**Часть 4: функция vx (x-координата вершины)**
1. **Начало функции**: получение k (номер вершины 1..4), d1, d2, a.
2. Перевести угол в радианы: rad = a * PI / 180.
3. В зависимости от k:
   - k = 1: вернуть -0.4 * d1;
   - k = 2: вернуть 0.6 * d2 * cos(rad);
   - k = 3: вернуть 0.6 * d1;
   - k = 4 (по умолчанию): вернуть -0.4 * d2 * cos(rad).
4. **Конец**.

**Часть 5: функция vy (y-координата вершины)**
1. **Начало функции**: получение k, d1, d2, a.
2. Перевести угол в радианы: rad = a * PI / 180.
3. В зависимости от k:
   - k = 2: вернуть 0.6 * d2 * sin(rad);
   - k = 4: вернуть -0.4 * d2 * sin(rad);
   - иначе (k = 1 или 3): вернуть 0.
4. **Конец**.

**Часть 6: функция in_quad (проверка принадлежности точки четырёхугольнику)**
1. **Начало функции**: получение x, y, d1, d2, a.
2. Инициализировать флаги pos = 0, neg = 0.
3. Для каждого ребра k от 1 до 4:
   - определить следующую вершину next (1→2→3→4→1);
   - вычислить координаты вершин (x1, y1) и (x2, y2) через vx и vy;
   - вычислить векторное произведение cross = (x2 - x1)*(y - y1) - (y2 - y1)*(x - x1);
   - если cross > 1e-9, установить pos = 1;
   - если cross < -1e-9, установить neg = 1.
4. Если pos и neg одновременно истинны, точка вне фигуры (вернуть 0), иначе внутри или на границе (вернуть 1).
5. **Конец**.

**Часть 7: функция dist (расстояние от точки до отрезка)**
1. **Начало функции**: получение px, py, x1, y1, x2, y2.
2. Вычислить вектор отрезка (dx, dy) = (x2 - x1, y2 - y1).
3. Найти проекцию точки на прямую: t = ((px - x1)*dx + (py - y1)*dy) / (dx*dx + dy*dy).
4. Ограничить t отрезком [0, 1].
5. Вычислить ближайшую точку на отрезке: cx = x1 + t*dx, cy = y1 + t*dy.
6. Вернуть евклидово расстояние от (px, py) до (cx, cy).
7. **Конец**.

**Часть 8: функция f_char (выбор символа для точки)**
1. **Начало функции**: получение x, y, d1, d2, a, sym.
2. Для каждого ребра k от 1 до 4:
   - определить следующую вершину next;
   - получить координаты вершин (x1, y1) и (x2, y2);
   - вычислить расстояние от точки до ребра с учётом масштабирования по X (умножение на 2 для компенсации вытянутости символов):
     - ddx = (x - x1) * 2.0, ddy = (y - y1);
     - sx = (x2 - x1) * 2.0, sy = (y2 - y1);
     - t = (ddx*sx + ddy*sy) / (sx*sx + sy*sy), ограничить t на [0, 1];
     - ex = ddx - t*sx, ey = ddy - t*sy;
     - если sqrt(ex*ex + ey*ey) < 0.5, вернуть sym.
3. Если ни для одного ребра условие не выполнено, вернуть пробел ' '.
4. **Конец**.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>
#include <math.h>

#define PI 3.1415926535

double vx(int k, double d1, double d2, double a);
double vy(int k, double d1, double d2, double a);
int in_quad(double x, double y, double d1, double d2, double a);
int param_ok(double d1, double d2, double ang);
double dist(double px, double py, double x1, double y1, double x2, double y2);
char f_char(double x, double y, double d1, double d2, double a, char sym);
double S(double d1, double d2, double a);

int main()
{
    setlocale(LC_ALL, "Ru");

    puts("Задание 3");

    double d1, d2, ang;
    printf("Введите d1: ");
    scanf("%lf", &d1);
    printf("Введите d2: ");
    scanf("%lf", &d2);
    printf("Введите угол между диагоналями (в градусах): ");
    scanf("%lf", &ang);
    printf("\n");

    int op;
    while (1) {
        printf("\n--- Меню для четырехугольника ---\n");
        printf("1 - рассчитать площадь\n");
        printf("2 - вывести определение фигуры\n");
        printf("3 - нарисовать фигуру\n");
        printf("0 - выход\n");
        printf("Ваш выбор: ");
        scanf("%d", &op);

        if (op == 0) {
            break;
        }

        switch (op) {
        case 1: {
            if (!param_ok(d1, d2, ang)) {
                puts("ошибка: d1 и d2 должны быть больше 0, угол от 0 до 180");
            }
            else {
                printf("S = %lf\n", S(d1, d2, ang));
            }
            break;
        }
        case 2:
            printf("Четырёхугольник - это геометрическая фигура (многоугольник), которая состоит из четырёх точек (вершин) и четырёх отрезков (сторон), последовательно соединяющих эти точки. При этом должны соблюдаться два условия: никакие три из данных точек не лежат на одной прямой; соединяющие их отрезки не пересекаются (не имеют общих внутренних точек).\n");
            break;
        case 3: {
            if (!param_ok(d1, d2, ang)) {
                puts("ошибка: d1 и d2 должны быть больше 0, угол от 0 до 180");
            }
            else {
                char sym;
                printf("Введите символ, из которого будет строиться фигура: ");
                scanf(" %c", &sym);

                double ymax = fmax(fmax(vy(1, d1, d2, ang), vy(2, d1, d2, ang)),
                    fmax(vy(3, d1, d2, ang), vy(4, d1, d2, ang)));
                double ymin = fmin(fmin(vy(1, d1, d2, ang), vy(2, d1, d2, ang)),
                    fmin(vy(3, d1, d2, ang), vy(4, d1, d2, ang)));
                double xmax = fmax(fmax(vx(1, d1, d2, ang), vx(2, d1, d2, ang)),
                    fmax(vx(3, d1, d2, ang), vx(4, d1, d2, ang)));
                double xmin = fmin(fmin(vx(1, d1, d2, ang), vx(2, d1, d2, ang)),
                    fmin(vx(3, d1, d2, ang), vx(4, d1, d2, ang)));

                printf("\n");
                for (int r = (int)ceil(ymax); r >= (int)floor(ymin); r--) {
                    for (int cx = (int)floor(xmin * 2); cx <= (int)ceil(xmax * 2); cx++) {
                        putchar(f_char(cx * 0.5, r, d1, d2, ang, sym));
                    }
                    putchar('\n');
                }
            }
            break;
        }
        default:
            printf("Неверный выбор! Попробуйте снова.\n");
        }
    }
    return 0;
}

int param_ok(double d1, double d2, double ang)
{
    if (d1 <= 0 || d2 <= 0 || ang <= 0 || ang >= 180) {
        return 0;
    }
    return 1;
}

double S(double d1, double d2, double a)
{
    return 0.5 * d1 * d2 * sin(a * PI / 180.0);
}

double vx(int k, double d1, double d2, double a)
{
    double rad = a * PI / 180;
    switch (k) {
    case 1:
        return -0.4 * d1;
    case 2:
        return 0.6 * d2 * cos(rad);
    case 3:
        return 0.6 * d1;
    default:
        return -0.4 * d2 * cos(rad);
    }
}

double vy(int k, double d1, double d2, double a)
{
    double rad = a * PI / 180;
    switch (k) {
    case 2:
        return 0.6 * d2 * sin(rad);
    case 4:
        return -0.4 * d2 * sin(rad);
    default:
        return 0;
    }
}

int in_quad(double x, double y, double d1, double d2, double a)
{
    int pos = 0, neg = 0;
    for (int k = 1; k <= 4; k++) {
        int next = (k == 4) ? 1 : k + 1;
        double x1 = vx(k, d1, d2, a), y1 = vy(k, d1, d2, a);
        double x2 = vx(next, d1, d2, a), y2 = vy(next, d1, d2, a);
        double cross = (x2 - x1) * (y - y1) - (y2 - y1) * (x - x1);
        if (cross > 1e-9) {
            pos = 1;
        }
        if (cross < -1e-9) {
            neg = 1;
        }
    }
    return !(pos && neg);
}

double dist(double px, double py, double x1, double y1, double x2, double y2)
{
    double dx = x2 - x1;
    double dy = y2 - y1;
    double t = ((px - x1) * dx + (py - y1) * dy) / (dx * dx + dy * dy);
    if (t < 0) {
        t = 0;
    }
    else if (t > 1) {
        t = 1;
    }
    double cx = x1 + t * dx;
    double cy = y1 + t * dy;
    double ex = px - cx;
    double ey = py - cy;
    return sqrt(ex * ex + ey * ey);
}

char f_char(double x, double y, double d1, double d2, double a, char sym)
{
    for (int k = 1; k <= 4; k++) {
        int next = (k == 4) ? 1 : k + 1;
        double x1 = vx(k, d1, d2, a);
        double y1 = vy(k, d1, d2, a);
        double x2 = vx(next, d1, d2, a);
        double y2 = vy(next, d1, d2, a);

        double ddx = (x - x1) * 2.0;
        double ddy = (y - y1);
        double sx = (x2 - x1) * 2.0;
        double sy = (y2 - y1);

        double t = (ddx * sx + ddy * sy) / (sx * sx + sy * sy);
        if (t < 0) t = 0;
        else if (t > 1) t = 1;

        double ex = ddx - t * sx;
        double ey = ddy - t * sy;

        if (sqrt(ex * ex + ey * ey) < 0.5) {
            return sym;
        }
    }
    return ' ';
}
```
